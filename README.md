# JS_basics

My notes and practice scripts while learning the fundamentals of JavaScript.

## Topics covered

| File | Topic |
|------|-------|
| `01_variables.js` | `const`, `let`, `var` |
| `02_datatypes.js` | Data types, strict mode |
| `03_datatype_conversion.js` | Converting between types |
| `04_Strings_to _numbers.js` | Strings to numbers |
| `04_comparisons.js` | Comparison operators |
| `datatypes_summary.js` | Primitive vs non-primitive types |
| `stack_and _heap.js` | Stack vs heap memory |
| `strings.js` | String basics |
| `basics/1.js`, `test.js` | Hello World scratch files |
| `exp.cpp` | A small C++ experiment on `1 + "1"` behaviour (for comparison with JavaScript) |

Values such as the "account password" in `01_variables.js` are dummy examples, not real credentials.

## Getting started

Prerequisite: [Node.js](https://nodejs.org/).

```bash
node 01_variables.js
```

Any file can be run the same way. A VS Code dev container (Node.js) is provided in `.devcontainer/`.

## Roadmap / known limitations

- Some file names contain spaces (e.g. `04_Strings_to _numbers.js`); wrap them in quotes when running.
- Learning notes, not a library; there are no automated tests.
